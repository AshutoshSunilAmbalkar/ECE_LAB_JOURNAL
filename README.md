## ECE Lab Journal

## Overview of the project 
This is an easy-to-use modular Python terminal application that replaces the manual logbooks in the Electronics and Communication Engineering (ECE) lab. It keeps track of the lab equipment and parts in a local text file (inventory.txt) to avoid loss of data when the program is closed. 

## Features
Add Equipment: Save new components and their quantities to the database.
View Inventory: Read and display all currently available items in the lab.
Update Quantities: Change the amount of a specific item.
Delete Equipment: Remove items from the lab records entirely.
File Persistence: Automatically creates and reads from a text file to store data

## Technologies/tools used 
Python 3
Standard os library
File I/O (.txt storage)

## System Requirements for runnning the code
To run this project you need the following:
* Python : Python 3.x is necessary to run the project
* Dependencies : No Dependencies , code relies on python's built in 'os' module
* Configuration : No Special Configuration needed , a file called 'inventory.txt' will automatically be generated

## How to use my project
1. Download or clone this repository to your local computer.
2. Open your system's terminal or command prompt.
3. Navigate to the root folder of this repository where the Python script is saved.
4. Execute the program by typing the following command:
   `python main.py`
5. The interactive menu will appear in your terminal. 
6. Type `1` to add new equipment, `2` to display your current inventory, or `3` to exit and save the program.
