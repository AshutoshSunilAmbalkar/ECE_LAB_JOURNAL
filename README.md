## ECE Lab Journal

## My Aim for making this project
This project will help you maintain the records in a ECE Lab


## System Requirements for runnning the code
To run this project you need the following:
* Python : Python 3.x is necessary to run the project
* Dependencies : No Dependencies , code relies on python's built in 'os' module
* Configuration : No Special Configuration needed , a file called 'inventory.txt' will automatically be generated


## How to use my project
1. Download or clone this repository to your local computer.
2. Open your system's terminal or command prompt.
3. Navigate to the root folder of this repository where the Python script is saved.
4. Execute the program by typing the following command:
   `python main.py`
5. The interactive menu will appear in your terminal. 
6. Type `1` to add new equipment, `2` to display your current inventory, or `3` to exit and save the program.
